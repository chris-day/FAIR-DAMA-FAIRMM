# Privacy choices

This documentation uses Zensical's consent form to remember your privacy choice in your browser. Use **Change cookie settings** in the footer at any time to review or change it.

The site does not configure analytics or advertising. Its fonts, search, styles, and favicon are served with the site. The repository link leads to GitHub. Optional GitHub repository details in the site interface are off until you allow them in the consent form; that choice controls requests made by the Zensical repository feature.

Interactive Sankey diagrams are embedded from this site's own files after you select **Load interactive diagram**. The diagrams then request D3 and D3 Sankey from jsDelivr. This is a separate, explicit action and is not controlled by the GitHub consent choice. Static diagram images and the surrounding documentation are available without opening an interactive diagram. Opening an external source or licence link takes you to that provider's site.

The configured production documentation URL is `https://fair-dama-fairmm.perdl.com/`. The GitHub Pages deployment workflow builds this site, but its custom-domain and DNS settings must be maintained in the hosting configuration. A local preview is not the production site. Source copyrights and licences remain with their respective components and are noted on the relevant documentation pages.

The consent form and request controls describe this site's behavior; they do not establish legal compliance on their own. Hosting logs and retention policies depend on the hosting provider's settings.
